# Contributors

## Garan / 七堂伽藍_

Project creator and release maintainer. Defines product direction, turns user feedback into concrete requirements, resolves behavior and compatibility decisions, and owns public releases.

## Midsummer

## Solstice

Reliability developer and reviewer. Works on memory-consolidation safety, runtime configuration recovery, partition database failure handling, regression coverage, and release verification.
